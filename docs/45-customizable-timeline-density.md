# 组合趋势自定义显示密度 · 2026-11-07

用户认为曲线区域密度偏低，本批增加可调显示偏好，延续已有蓝白工作区。

- 默认紧凑：曲线64px、用药36px；标准94/50px；宽松132/66px。
- 自定义曲线行高56～160px、用药行高32～80px。
- 时间网格支持稀疏/自动/密集。密集时增加辅助网格，仍保留主时间标签，避免标签堆叠。
- 原始观测点可自动简化或全部显示；检验与候选报告仍保留独立点，不把稀疏原始数据补成更密的采样。
- 设置面板可收起、一键恢复默认。localStorage仅保存本机显示偏好，不保存患者标识、数值、病程、用药名称或临床规则。损坏数据/存储不可用时安全回退。
- SVG坐标和游标按行高同步调整，用药点仍可点击追溯；不只压缩外层高度。曲线缩略、单位、时间边界和原始值不变。
- 密度调整不重新请求数据、不改变所选记录或时段、不清除当前有效的范围AI答案；切换患者/范围仍按原逻辑处理。

验证：前端89项通过；编译后合成API浏览器24个综合场景通过，0运行错误。新增检查预设与自定义实际高度、原始点数量/时间网格、记录及请求次数不变、AI保留、设置保存/页面重建恢复、恢复默认，以及偏好编码不包含额外临床字段。实际查看自定义密度截图。生产构建约407.94kB，低于预算；JAR重新打包，内嵌静态文件与最终前端核对一致。
