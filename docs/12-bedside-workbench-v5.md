# 床旁脓毒症工作台 v5

按现场操作习惯重排展示内容。只改前端展示，不改源数据读取、后端判断规则、宿主登录或数据库。

## 页面结构（3 个标签）

| 标签 | 内容 |
| --- | --- |
| 概览 | 首行：当前最需处理的异常（红 = 危急，橙 = 异常），qSOFA，待处理预警 / 任务（数量为 0 时不显示）。下面依次是关键指标卡、1 小时集束化、器官功能。生命体征曲线默认收起。 |
| 预警处理 | 当前患者待处理预警，下方是执行任务。处理原因使用快捷选项。 |
| 记录与依据 | 默认显示记录单（时间为列、指标为行，危急 / 异常着色，点单元格查看来源）。可切换趋势图或明细。 |

## 提示阈值（只用于着色，不构成诊断）

| 指标 | 异常 | 危急 |
| --- | --- | --- |
| MAP（有创 / 无创分别判断） | < 70 | < 65 |
| 收缩压 | ≤ 100 | < 90 |
| 乳酸 | ≥ 2 | ≥ 4 |
| 呼吸 | ≥ 22 | ≥ 30 或 < 8 |
| GCS | < 15 | ≤ 8 |
| 心率 | > 100 或 < 50 | ≥ 130 或 < 40 |
| 体温 | > 38 或 < 36 | ≥ 39.5 或 < 35 |
| SpO₂ | < 92 | < 88 |

代码位置：`frontend/src/clinical-flags.ts`。院内有不同阈值时只需改这一处。

## 1 小时集束化

- 时间零点固定显示“未确认”，不计算倒计时，直到院内确定 T0 规则。
- 乳酸：有有效结果时显示数值和距今时间；≥2 且超过 2 小时提示“需复测”。只有未确认归属的报告时显示“归属未确认”，不算已有结果。
- 血培养、抗菌药、补液：源数据未接入，显示“未接入”，不推断是否完成。
- 血管活性药：只反映源记录有无，MAP<65 且无记录时标橙。

## 器官功能

循环（MAP / 升压药）、中枢（GCS）使用现有数据。PaO₂/FiO₂、血小板、胆红素、肌酐 / 尿量当前未接入，明确显示“未接入”。SOFA 使用宿主已录入的评分（`score.scoreType=sofa`），并显示 24 小时内的变化。

## 宿主角标消息（子页面 → 宿主）

每次概览读取完成、预警或任务处理后发送：

```json
{
  "type": "SmartCareSepsisStatus",
  "version": 1,
  "patientId": "24位患者ID",
  "level": "critical | abnormal | normal | unknown",
  "summary": "MAP 58 偏低 · 乳酸 3.5 偏高",
  "pendingAlerts": 1,
  "pendingTasks": 0
}
```

- 只发送到已验证的宿主来源，不使用 `*`。
- 数量读取失败时为 `null`，宿主不能显示为 0。
- `unknown` 表示数据不全，不能显示为低风险。
- 宿主需自行监听该消息并在患者列表或菜单上显示角标；旧宿主不处理此消息也不受影响。
- 安全握手模式（`icu.sepsis` 协议）发送 `type: "STATUS"`，payload 相同。

## 角色

宿主角色只有护士（无医生角色）时，集束化面板占满一行并排在器官功能前面。

## 未变化

后端规则、源数据映射、缺项不计零、IBP / NIBP 不自动择优、候选乳酸不参与判断等规则全部保留。未接入 AI，未进行临床验证。
