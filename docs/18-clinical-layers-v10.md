# v10 床旁医生视图与科室主任质控看板

参考 TREWS（判断 + 依据 + 医生确认/排除）、Epic Sepsis Navigator（清单 + 计时器）、ICCA（质控报表独立），以及国家重症质控指标 2024 版 ICU-05 与"感染性休克救治能力指数"过程子指标。只改变呈现方式，不改变任何判定规则或阈值。

## 医生视图（概览）
1. **判断层**：标题先给结论（"感染性休克" / "疑似感染性休克，待复核"）与"T0 后 Xh"；下一行列出依据（首次乳酸、MAP、升压药、感染证据），再下一行是当前生命体征异常。有待处理预警时可直接"确认 / 排除"，选择原因（"其他"必须填写说明），提交到 `/alerts/{id}/review`，留痕规则与预警处理页一致。
2. **处置层**：Bundle 卡片默认"床旁"视图——"下一步"项与剩余时间（≤30 分钟变红），措施清单写相对 T0 的时间（如 抗菌药 +0:40、血培养 +0:50，并标注"早于血培养"），底部是 1h/3h/6h 结果与未达标原因。原 1h/3h/6h 逐项矩阵移到"质控"视图（质控角色默认）。
3. **背景层**：乳酸卡始终显示检验时间，并给出清除率（首次 → 最近）；MAP 卡写出升压药名称；器官功能无数据写"24h 内未取得结果"。

## 主任视图（"科室质控"页签，医生/质控角色可见）
- `GET /api/v1/quality/icu05-board?days=7|30`：按入科时间取本科室病例（≤300 例），用与床旁相同的 ICU-05 规则重算（结果缓存 5 分钟）。
- 1h/3h/6h 完成率 = 达标 /（达标 + 未达标）；"无法判定""进行中"单列，不计为未完成。分母：符合感染性休克判定且入院 24h 内进 ICU；不符合或无法确认纳入的单列。
- 过程指标：1h 内抗菌药、抗菌药前留取血培养、1h 内监测乳酸；氧代谢监测（ScvO₂ 等）数据源未接入，显示"未接入"。
- 需要关注的病例：进行中且有待做项的按剩余时间排序，其后是疑似待复核、未达标（列出原因）。
- 同一看板也显示在独立版"质控分析"页顶部。

## 限制
- 看板按当前时刻重算，不等同于上报口径的最终结果；血培养时间取医嘱审核时间。
- 嵌入授权为单患者时，看板仍显示本科室病例的床号与姓名（与"全科室预警"一致，只读）。
