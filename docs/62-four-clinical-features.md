# 2026-11-21 四项功能交付

## 入口与行为
1. 概览 → 数据质量与时效：按观察项显示可用、待核对、过期、未取得、来源异常；近24小时记录分箱图、原因筛选、来源和真实时点。数据质量颜色不代表病情严重度。读取近7天，上限及来源失败独立标注；基础预警与专项/MEWS窗口不同，不据此代替评分。
2. 自动AI下方 → 研判变化：分别对比证据与研判表述，忽略事实编号变动；不会把未再采用当恢复。只比较同一账号/患者/住院的本页会话成功研判，最多20组内存记录，无浏览器持久化；首次、重复缓存和较早缓存有独立处理，不倒序覆盖基线。
3. 组合趋势 → 点击真实用药执行/操作点：选择前后各1/3/6/12/24小时；跨轨显示锚线与前后窗口。卡片显示前末次、后首次实际记录、样本数和差值；缺测保持空值，截断窗口明确提示。未使用待核对报告，不插值，不推断因果或疗效。
4. 医生概览 → AKI用药复核：关联近7天真实执行/操作、肌酐与尿量背景、已核对RRT证据；按有限通用名词典标注NSAIDs、氨基糖苷、ACE抑制剂、ARB及利尿剂线索。停止/暂停仍显示真实操作含义，不宣称当前正在使用。未分类清单、来源不完整、剂量及RRT缺项明确保留。复选框仅本页核对，未保存，不形成医嘱；不自动停药或计算推荐剂量。
