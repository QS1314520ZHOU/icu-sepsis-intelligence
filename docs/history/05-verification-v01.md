## 已实测的软件路径
- 正常模拟患者不触发预警，缺失患者返回无法评估，不填正常值。
- 模拟感染伴血流动力学异常产生可追溯筛查证据及预警，而非诊断。
- 无模型时4/12/24小时riskValue与riskValueType均为空；qSOFA明确整数筛查分，不作为概率。
- 同请求幂等，不同负载复用键409，预期版本冲突不产生部分任务。
- 医生接收/确认/驳回/暂缓/关闭状态控制，护士无诊断确认权限，未授权401/越权403。
- 执行记录带事件/入库时间及原始来源ID；按时、超时、触发前完成分开。
- 适用性待审核不计分母；例外排除；空分母率为空；同口径下钻与统计服务直接核对。
- 当前写操作、历史、审计和幂等记录使用真实Mongo事务。
- API失败注入在前端显示trace及错误，不再显示“零患者/未找到患者”假象。此为浏览器网络故障注入测试，不是生产数据库故障演练。

## 本次实际发现并修复
1. Spring Security BCrypt字符串缺少编码器标识，模拟用户测试未覆盖真实认证；修复并补真实HTTP Basic成功/错误密码回归。
2. 窄屏证据表格字段被过度挤压；改为表格区域横向滚动，页面本身不横向溢出。
3. 异步刷新完成前截图可能读取旧状态；验收脚本增加持久化状态等待，执行后明确显示按时完成但临床审核仍待处理。
4. 异常状态曾同时显示空列表和零患者；修复并增加浏览器断言。
5. 初始Angular运行及构建依赖有已知漏洞；按扫描建议同主版本修复到runtime20.3.34、CLI/build20.3.41，再全量构建与扫描。
6. 运行时覆盖同名jar可能导致延迟加载/关闭失败；启动脚本改为版本哈希运行副本和PID保护，并实测独立启动。
