# 2026-11-08 乳酸指南核查与时序AI

已核查权威原文：SSC2026 https://www.sccm.org/clinical-resources/guidelines/guidelines/surviving-sepsis-campaign-international-guidelines-for-management-of-sepsis-and-septic-shock-2026 ；Sepsis-3 https://jamanetwork.com/journals/jama/fullarticle/2492881 。前者支持乳酸测量与序贯监测，并说明不能单凭一项生物标志物确诊或排除脓毒症；后者休克临床构成为脓毒症背景、充分容量复苏后仍需升压药维持MAP≥65及乳酸>2mmol/L等。不可将项目≥2候选阈值冒称上述完整确诊标准。所核查条款不能批准院内K1的两套窗口，K1仍待确认。

最近值和窗口最高值不作二选一：最近反映末次测量，最高反映指定窗口峰值，二者均须结合时序、血压、升压药、感染和病程解释。卡片现在显示最近值及近24h峰值时间，不再把K1门控选中值误标为“首次”计算清除率。AI decision原有趋势摘要之外，新增乳酸逐点时序（最多最近24个时点，截断明确标注；全窗峰值仍在摘要），要求结合最近/峰值/中间变化研判，不能伪造疗效或因果。时间类型未确认不把记录时间当采样时间或复苏后时间。未确认住院归属的数据不进入有效趋势。

修复明确程序问题：SmartCare来源原先无条件带“乳酸报告采样、归属未确认”说明，会误导页面和AI。现按具体背景记录的归属/有效性分别说明；已关联本次住院的有效血气乳酸不会因为另有待核对检验报告而失效。源记录真实单位、时间和归属核验仍保留，不因联网查询而伪造本地数据完整性。

验证：后端403项400通过3跳过；生产构建及JAR打包成功，35浏览器场景通过。新增已确认血气不被统一待确认、待核对报告不污染有效记录、5.8→1.7→3.1完整时序同时含最新与峰值测试。配置密钥、K1和正式分子分母未改。未在医院数据库或真实模型做现场验证，不能声称所有乳酸漏取均已修复。
