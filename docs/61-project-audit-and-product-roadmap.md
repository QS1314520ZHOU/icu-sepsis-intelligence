| 检验复核只校验源报告指纹，没有校验复核版本 | 两位医生的旧表单可能覆盖较新的确认或撤销 | 请求携带expectedId；业务库原子比较头版本；旧版本或并发竞争返回409；Mongo合成库双线程验证仅一个保存成功 |
| 同一次读取分别查询显示用复核记录与计算用复核记录 | 并发撤销时可能出现列表与计算依据不同 | resolve共用一个复核快照；每次读取由两次复核查询降为一次；测试在下一次查询返回撤销记录，确认同次显示与计算仍一致 |
| 历史复核缺观察时间仍可能显示已确认 | 显示状态与实际是否可用不一致 | 显示与计算共用适用性判断，缺时间或住院依据时保留待核对 |

| AI服务检测遇到配置异常可能整次中断 | 一个模型配置错误遮蔽其他服务状态 | 逐项捕获安全错误类别并继续检测；聊天未配置明确显示；不返回异常原文；未向模型发送患者数据 |
| 医生切换护士视图后仍显示病程同步按钮 | 可见操作与当前视图不一致 | 按当前视图隐藏按钮，后端权限校验保持独立 |
