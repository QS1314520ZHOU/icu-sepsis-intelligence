# 临床工作台布局修订 · 2026-11-07

## 问题与结果

用户截图为历史 Bundle / 护理视图。护理视图隐藏器官功能后，CSS 仍为双列，且原有“护理 Bundle 跨列”规则只命中内部 section，无法使实际 grid 子项 icu05-card 跨列，造成右侧空白。AI 组件也作为第三个 grid 子项落入下一行半宽区域。

本次完成：

- 给实际组件宿主设定宽度与显示规则，护理视图显式使用单列网格；历史 Bundle 铺满可用宽度。
- 宽屏护理措施以卡片并排显示，突出措施、相对 T0 时间、执行内容和待核对状态；窄屏恢复逐行布局。
- 历史记录原显示“待做”的缺项改为“未见记录”，不推断未执行，不发起当前任务；底层判定结果保持原样。
- 医生视图仍可对照 Bundle 与器官功能；AI 从双列网格移出，使用独立全宽区域，顶部增加 Bundle / 趋势 / AI 快捷入口。
- AI 快捷入口仅定位并聚焦，不自动发起模型请求。护理视图既有工具可见性与角色权限不变。
- 新增深蓝工作台导航、统一标题与分隔线、蓝绿色操作入口，异常仍用红/琥珀色；压缩流程区与宽屏 MEWS 区的重复留白。
- 跳转目标预留固定患者导航栏高度，避免标题被遮挡。窄屏区域纵向排列。

## 参考与设计取舍

查阅开源医疗界面的患者工作台组织方式，借鉴信息分区与患者上下文组织思路；使用本项目 Angular / CSS 实现，没有引入 React/Carbon 依赖，也未复制第三方组件代码或素材。
