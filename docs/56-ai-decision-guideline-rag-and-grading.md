# 2026-11-19 自动AI研判、指南RAG与推荐分级

> 本文为阶段记录；后续实现与当前限制见 [57号记录](57-specialty-evidence-review-and-vector-cache.md)。

## 实际链路
医生概览自动请求 decision → 服务端读取当前住院结构化证据、近24小时趋势与七日肌酐比较 → 读取最多六份当前住院已保存病程快照的有限脱敏片段 → 病种定向指南检索 → 院内推理模型 → 引用、数字、剂量、推荐强度校验 → 医生复核。

病程原文不进入指南向量索引。知识库为版本化的公开指南及本院规则；使用现有院内embedding模型构建内存向量，与BM25作排名融合。无需新增向量数据库。尚未实现持久化向量索引；重启会重新构建。病程片段来源、时间未知及正文截断限制继续明确显示，不声称全文复核。读取病程失败不阻断结构化证据研判，不把失败解释为无感染。

新增NICE NG148 AKI三个摘要条目：肌酐变化、尿量、监测。官方网站核实：
https://www.nice.org.uk/guidance/ng148/chapter/Recommendations
包括1.3.1、1.3.2与1.2.2。摘要仅作为临床复核参考，不声明NICE推荐强度或证据质量分级。器官/肌酐事实优先检索专项指南，避免被通用脓毒症条目挤出。已有SSC 2026知识仍保留：
https://www.sccm.org/clinical-resources/guidelines/guidelines/surviving-sepsis-campaign-international-guidelines-for-management-of-sepsis-and-septic-shock-2026

## 此轮修订
- 每次模型结果携带实际RAG检索元数据：bm25/hybrid/mixed、查询数、语义查询数、降级原因和索引状态。索引ready但查询失败时，显示关键词检索；不能把已配置或已建索引当成成功使用向量。
- 拒收重复索引、缺失/异维、非数值、非有限和零向量，避免错误排名；异维查询降级关键词。
- 自动研判输入指纹加入五分钟刷新时段；概览刷新触发时可重新读取病程/肾脏证据，无需按钮。仍受可见性、医生权限与编辑中保护控制；不是后台实时模型推送。
- 弱推荐保留。建议旁显示条件性推荐标签，证据质量放在悬浮与展开依据。明确强推荐/条件性推荐/最佳实践，不自行分级；弱推荐被写成强制要求的模型条目过滤。不更改现行Bundle正式分子分母。
