# 判定项、SOFA 人工复核与来源完整性（2026-11-06）

本记录接续 docs/23。L1 病例排除保持既有实现；本批新增 L2 判定项覆盖、L3 实验性 SOFA 人工分项，以及来源完整性保护。尚未完成整个交接计划。

## 已实现

- L2：S1–S4、I1–I3、K1/K2 与 1h/3h/6h 的 A1/B1/B2/B3/C1/C2/C3 独立覆盖。A2 仍为暂定展示项。保留自动快照、人工值、原因、操作者、时间、规则版本、T0；撤销后恢复基于当前证据的自动结果。覆盖 B1/B2 后重算 B3，不虚构执行或采样时间；再重算相关完成链。其他窗口保留原结果。
- K1 特殊限制：窗口未确认时，前后端均拒绝 K1 覆盖；仍显示“乳酸取值窗口待确认”。最高值方式不等于窗口已确认。不将未知处理为不满足，不因本批改动另选统计分子、分母。
- L3：经典 SOFA 与 SOFA-2 各自保存六项人工分数 0–4；缺项不补零，只有六项均可用才显示总分，部分合计明确标注。自动分项引擎尚未接入，本批不是自动 SOFA 评分交付；实验性分项不影响 ICU-05 候选或统计。
- 新接口 /api/v1/patients/{patientId}/icu05-overrides（GET/POST）及 /{id}/revoke（POST）。医生或质控角色、宿主患者范围、幂等键、保存指纹与撤销版本检查；独立集合 sepsis_icu05_override、有效键唯一索引、事务与审计。只在现有 ICU 业务库建集合，不写医院来源库。
- 页面支持新增、保存、撤销和历史；未保存草稿阻止宿主患者切换，异步响应校验患者与住院上下文。
- 看板人工覆盖率：分母为成功取得可用结果的病例；分子为至少一条生效覆盖的去重病例。分别统计病例排除、判定项和 SOFA，各层可重叠；“未覆盖”不能解释为“未复核”。旧版本/T0 不匹配的覆盖单列待复核。
- 看板单列候选条件无法判定；显示最长缓存五分钟与最早计算时间，不保证实时。证据来源失败/截断标记统计不完整，不把相关未知改为失败。
- 九类限量读取均多读一条区分恰好达到上限与确实截断；截断标记来源失败、保留已读原始证据、关闭游标。截断药品字典不缓存为完整字典；检验乳酸回退来源失败同样传播到判定。
- 血气与检验乳酸均保留原值、原单位、时间含义、来源；仅明确为 mmol/L 的有效非负有限数值参与计算，不自行换算或补单位。现场单位字段仍需对照字典核实。不能将血气时间宣称为采样时间；authTime 明确是结果时间。
- T0 前血管活性执行中的未知动作保持状态未知；加减量不消除未知，后续明确开始/恢复才恢复已知状态。
- 看板、复核面板与独立质控页按需载入，保留原功能和权限；当前初始包 645.19 kB，低于 650 kB 警告预算。
