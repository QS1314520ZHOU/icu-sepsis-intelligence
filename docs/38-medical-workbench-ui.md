# 2026-11-07 医疗工作台视觉调整

本批仅调整页面布局、样式和合成 UI 测试，不更改临床计算、数据接口、模型配置、权限和 K1 状态。

## 页面调整

- 统一蓝绿主色、浅灰背景与白色卡片，减少过度鲜艳的按钮和边框；红色、橙色继续表示原有异常等级。
- 统一患者栏、页签、按钮、下拉框、输入框和焦点样式；改善次要文字与未知状态的对比度。
- 关键指标优先显示，MEWS 移至指标之后；MEWS 分数、时间规则、体温沿用标记与展开依据保留。
- AI 功能改成对齐的工具网格，宽屏四列、中等宽度三列、窄屏两列；提问、依据、原文、反馈和草稿能力保留。
- 统一 Bundle、器官功能、记录表格和科室看板的间距与标题层级。详细依据仍可展开，重要缺项、异常、时间与来源没有删除。
- 支持窄宿主 iframe，保留键盘焦点和减少动画偏好，不加载外部字体或图片，内网可用。
