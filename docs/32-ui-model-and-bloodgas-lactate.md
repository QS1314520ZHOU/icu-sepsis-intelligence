# UI、模型标识和血气乳酸读取修订

2026-11-06。依据用户截图排查，未访问医院数据库，也未保存或转发截图中的患者身份信息。

## 修改

- AI 反馈栏的可选耗时输入与按钮固定为紧凑高度；选择框统一高度、间距和边框，避免继承整页表单宽度及拉伸。
- 之前模型栏直接显示 LLM 网关响应中的 model 字段。源码没有 qwen3-14b 固定配置，不能据此确认真实部署模型。新增 requestedModel 记录本次实际请求参数，独立保留网关返回的 model；页面分别标注“请求模型”和“网关返回标识”。旧记录未保存请求参数时明确“请求模型未记录”，不推测。请求参数来自现有 AI_MODEL_FAST/AI_MODEL_REASONING 配置，未擅自替换用户模型、网关或密钥。更新后可重新生成，核对请求与返回是否一致；网关别名/实际权重仍须在内网核对。
- 概览血气读取原先只有 param_bg_P/Fratio，漏读 param_bg_Lac。现统一查询两项，保留原来源、记录时间及源字段，并按指标/时间区分同一文档内记录标识，防止冲突。血气 unit 未取得/不明确为 mmol/L 时仍展示候选值，标注单位待确认，不伪造单位或用于判断。
- 查询及逐记录检查均保留当前住院下限、请求时间范围与未来记录排除。10 月历史血气不能直接代替 11 月近期记录。
- 已取得但未参与判断的乳酸卡片显示“已取得…待核对”；AI 缺项说明明确“不等于未取得报告”。候选详情标注“待核对”，不显示绿色“正常”。已取得的检验报告仍保留本次住院关联、采样/结果时间和状态的核对要求，不自动升级为有效结果。
- 正式 K1 窗口继续待确认；不修改质控分子分母。
