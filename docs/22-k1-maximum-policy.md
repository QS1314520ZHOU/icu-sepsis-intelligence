# K1 最高乳酸口径落实（2026-11-06）

## 用户已确认

K1 暂按窗口内有效乳酸最高值计算，≥2 mmol/L 为成立；记录选中值、时间和来源。窗口起止必须按 V3 及继承规则确认，不明确时无法判定。本结果仅用于本地质控候选筛查，仍需 K2、感染证据与人工复核，不等同临床确诊。

## 实际实现

- 默认选值从 unconfirmed 改为 maximum，移除 earliest/latest 的实际判定路径；遗留不匹配配置返回未知并提示更新。规则版本为 ICU-05 v3-local-k1-max-20261106。
- K1 不再隐式沿用通用门控窗口。必须同时提供窗口起止和可追溯的规则来源；缺失、反向或无法评估时返回 null。
- 对显式确认窗口，取截至本次 asOf 已出现的有限、非负、标准化为 mmol/L 的乳酸最大值；缺失不补零。等于 2 成立，低于 2 不成立。
- 最大值并列时，取最早时间，再按来源 ID 排序，保证输入顺序变化后仍能稳定追溯。
- API 的 K1 项提供 number、unit、time、sourceId、windowFrom、windowTo、evaluatedTo、windowSource、windowConfirmed、scope。页面增加 K1 数值、时间、来源、窗口以及未知原因展示。
- 读取失败时不使用选中值确认候选；保留 K1 AND K2 三值逻辑及独立疑似预警。
