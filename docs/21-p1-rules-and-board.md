## 本批实际实现

- 本地 ICU-05 候选采用 K1 AND K2 三值逻辑；K1 OR K2 为独立疑似预警，不计分母。感染、器官功能与纳入条件仍分别判断。
- S4/K2 依据医院血管活性分类字典，单独提供 V3 严口径八种药物分类；不改变研究升压药清单。药物命中结果增加药名、分类、来源和执行时间；字典读取失败返回未知。
- K1 增加明确选值配置 app.icu05.k1-selection（maximum/earliest/latest）；默认 unconfirmed。V3 本地原文只有“窗口内取值”，未确认前不冒充已确定口径、不确认质控候选。测试中选值策略只用于合成数据。
- B1/B2 改为同一窗口内最新记录；B3 明确比较这两条记录，严格晚于才通过；保留首条记录时间，血培养标审核时间。
- T0 增加首条医嘱来源 ID 和时间含义；A1 保留来源及最高值；页面提供各窗口自动结果、来源、时间及首条记录追溯。
- 补液金额仅以已确认单位的实际输入量计算，整袋容量不代替实际输入量。现有医院适配尚无经核实的实际输入量字段，因此相关量判定保持未知。修正父级单位未读取以及缺单位默认 ml 的问题。
- A2 明确为暂定项，不把暂定的乳酸复测强制纳入最终达标计算。
- API schemaVersion 升为 2，规则版本 ICU-05 v3-local-20261106。保留兼容字段/状态枚举（isSepticShock/septic_shock），在版本 2 中其含义为本地质控候选，不是临床确诊；前后端须一同升级。
- 科室看板取消最近 300 例截断，汇总覆盖当前科室权限和所选入科范围中的已同步病例；明细每页 20 例。上限仍为 31 天，当前 UI 提供 7/30 天选择。读取失败标不完整；缓存键包含就诊与规则版本，避免跨就诊复用。
- 看板明确为本地可判定病例达标率，非正式上报率。独立疑似预警已接入现有预警生成路径。
