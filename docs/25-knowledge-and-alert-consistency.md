# 知识版本与预警一致性、联合验证（2026-11-06）

## 已实现

- 修复预警 ICU-05 解释中的旧口径：本地质控候选 K1 且 K2，独立疑似预警 K1 或 K2；不引用旧 MAP<65 组合来解释新 ICU-05 结果。床旁筛查自身口径保持独立。预警规则版本 screen-alert-v2。
- 人工病例/判定项/SOFA 覆盖保存或撤销后，事务提交事件使下一轮定时筛查不因旧指纹而跳过；科室看板缓存同时失效。这是本地复核事件，不代表已接入医院医嘱/检验事件。
- AI 预警解释默认按需；仅显式开启 app.alerts.auto-ai-explanation / ALERTS_AUTO_AI_EXPLANATION 才在新建预警后自动生成。AI 失败不影响规则预警。
- 知识增加类别（国际、国内、科室、系统；未分类兼容）、状态、适用范围、证据质量原文字段、内容摘要及稳定修订 ID；没有原文的证据质量保持空白，不补推荐等级。
- 同 docId 更新保留已加载版本和正文；同版本号内容不同拒绝加载，防止静默替换。草稿、退役与未来生效版本不进入当前检索。当前词法 BM25、可选向量及向量失败回退保留。
- 新增 GET /api/v1/knowledge/history?docId=...，通过既有认证返回已加载版本、当前标记及原文快照。检索引用及 AI 记录保存修订 ID；页面显示知识版本与来源。此功能只追溯部署中保留的版本文件，尚无数据库版本仓库或编辑审批界面；外部目录更新必须保留旧版文件，不能声称覆盖同一文件后可跨重启恢复。
- 将旧 ICU-05 和系统乳酸知识放入 classpath knowledge/history，当前检索改用与已确认代码一致的新版本，覆盖 MAP≤65、VASO_WIDE、K1 窗口待确认、最新 B1/B2 与 B3、实际补液量未知、A2 暂定项。历史旧条文只供追溯，不作为当前检索依据。
- 知识分类支持国内规范，但本批没有新增未经核对的国内规范正文；未改写国际指南医学内容。没有宣称知识管理等于医学正确性或完整语义校验。
